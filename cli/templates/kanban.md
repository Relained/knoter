# Kanban

> Column-based board. Each item stays on exactly one column; move items
> between columns instead of duplicating them.

- Captured but not yet scheduled work.

- Scheduled next; ready to start.

## In Progress

- Work currently underway, with owner or context when known.

## Review

- Finished work awaiting verification or feedback.

## Done

- Verified work with completion dates, newest first.
